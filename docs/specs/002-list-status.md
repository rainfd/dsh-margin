# 002 列表分页、状态与显式读写闸门

**状态：代码与自动化测试已落地；待 GUI/授权写入集成验收，尚未部署。**

## 前置条件

001 的详情/列表导航状态约定；核验当前后端分页、筛选及状态写入能力。历史“小库无需分页”不作为本期依据。

## 范围与非目标

- 默认未读；可切换已读、处理中、错误，状态名称以当前后端核验为准。支持分页、来源与标题/域名/标签搜索，切换筛选重置页码，返回详情前的列表不丢状态。
- 明确 `total`、当前页数及来源统计口径，不能用单页客户端搜索结果配服务器全量 total。后端不支持筛选时，选择有界扫描后过滤并标明截断/已加载范围；未完成扫描不得称为完整总数。限制请求数并处理数据变化导致的重复/空页。
- 读取与写入权限分离；默认禁写。工具注册、host 执行及 UI 写入口都受能力闸门控制；只隐藏按钮不算授权。
- 用户明确“读完/标已读”才写 `read`；明确“设为未读”才写 `unprocessed`，始终设置目标值，禁止 toggle。打开、滚到底、AI 摘要、存 Trilium 不隐式改状态。
- 待确认/失败保持原状态或重新读取，不虚报成功；请求期间防重复，成功后刷新受影响列表、计数与详情。
- 不包含删除、批量清理、任务自动完成或未读反向重开 Trilium 任务。

## API 核验需要

本地 host 列表尚未接收页码；客户端尝试 Margin `GET /api/candidates` 的 `page/page_size/status/source_type`，并单页本地搜索。逐项验证参数是否真正生效、排序稳定性、分页对象和最大页长，不能仅以 200 判定支持。

本地写客户端尝试 `PATCH /api/candidates/{id}/status`，body 为 `{status}`；当前后端契约、幂等性、冲突响应和授权均待核验。未读工具/浏览器写代理目前未实现，其路径与契约 **TBD**；后端不支持时禁用，不伪造接口。

### 2026-10-25 静态契约核验（为下一步实施准备）

本机 Margin `backend/app/api/candidates_router.py` 的列表签名只接受 `page/page_size/sort_by/status/category`，**没有 `source_type` 和全文搜索参数**；页长夹取到 1–100。插件当前透传来源参数不能保证有效，002 必须修正，不能复用现状当成功。

`backend/app/schemas/candidates.py` 的状态更新响应只含 `id/status/is_saved_to_trilium/updated_at`，**不是完整候选**。后续应单独映射状态 DTO 或成功后重取详情，不能继续用完整候选默认值覆盖标题/正文。以上是本机源码核验，不代表目标实例版本完全一致；尚未执行真实写入测试。

## 验收与测试

- 多页数据中，来源/搜索命中不局限于第一页；总数、页数、截断提示一致，空页可恢复；快切筛选无迟到覆盖。
- 默认禁写时工具和直接 host 请求均被拒绝；明确开启后仍需具体用户动作，缺实例/非法 ID/非法目标值不发写请求。
- 连续两次“标已读”不翻转；写失败/超时后重读确认；并发修改后 UI 与 Margin 真源一致。
- 阅读操作零写入；已读/未读不擅自改任务账本。

- 现有只读探针全部通过；本地 harness 显式注入仅 loopback 的测试 gate（不等于真实 DSH 浏览器会话验收），包括连接、列表、详情、缺失 ID、来源总数及跨站拒绝。

- 界面加入四种状态、30 条分页、筛选重置页码、部分结果提示；详情返回保留列表状态。
- 增加 `PATCH /api/dsh-margin/candidate-status`，只接受 `{id,status,marginUrl}`；status 限制为 read/unprocessed，实例链接与当前配置必须一致。默认禁写；连接会话/来源校验后，读请求体前后均检查实时写权限。
- 写接口映射部分确认 DTO；阅读器显式点击才写，锁定重复点击，确认后重新读取详情并刷新列表。确认已到但重读失败时显示不确定提示，不把旧状态当作回滚；无自动写重试。
- agent 工具增加 `margin_mark_unread`；两个写工具仅在开启时注册，并在执行时复查权限。列表工具改走同一有界查询，并标明不完整总数。
- 不写 Trilium、不重开任务、不在打开/滚动/摘要时自动已读。所有写集成测试使用本地假 Margin；尚未在真实文章上执行状态变更，也未开启运行中配置的写能力。
