# 001 插件内只读 Markdown 阅读器

**状态：实现及自动化测试已落地；待现有 DSH GUI 集成验收，不等于已部署。**

## 前置条件与依据

基线的主面板列表及详情代理可作为入口，原候选映射没有保留正文。2026-10-25 已核验本机 Margin 的 `CandidateDetailResponse` 与详情路由，正文契约为可空字符串 `content_md` / `content_text` 与布尔 `content_fetch_failed`。已对配置实例作只读抽样：候选 #873 的 Markdown 5652 字符、纯文本 3425 字符，正文提取未失败；列表没有携带全文。此为单篇抽样，不推断全库覆盖率。

## 范围

- 列表点击文章进入插件内详情，保留独立的「在 Margin 打开」降级入口，原站链接明确区分。
- 分离列表 DTO 与详情 DTO：仅详情提供 `contentMd`、`contentText`、`contentFetchFailed`，映射已核验后端 `content_md`、`content_text`、`content_fetch_failed`（缺失/null/错误类型降级为空正文与 false）。列表响应、列表工具、统计和缓存预热不携带正文。
- 优先非空 Markdown；缺失时按纯文本展示 `contentText`，不能把纯文本当 Markdown 或 HTML。两者皆空显示空正文/提取失败说明，不拿摘要冒充全文。
- 复用经过核验的 DSH Markdown 组件；禁用原生 HTML 执行、脚本、事件属性及危险 URL scheme。外链安全打开；图片不得附带凭据，远程图片策略需验证。不因“是 Markdown”就视作安全。
- 返回列表保留来源、搜索草稿/生效值、状态、页码及可恢复滚动位置；实例切换使旧详情失效。
- 加载、404、鉴权失败、超时、提取失败分别可辨；重试按钮只重新读取详情，不触发重新抓取或其他后端写入。切换 A→B、返回列表、卸载或换实例后，A 的迟到结果不得覆盖当前界面；使用请求序号/取消及实例身份校验。
- 正文走浏览器详情读取通道；现有 agent 工具保持精简，不自动将全文写入工具 transcript。

## 非目标

不标已读、不写状态、不导入、不重新抓取、不保存、不做高亮/批注、不做 AI。无全量复制、离线库或 HTML reader；后续由 002–008 独立启用。

## API 核验需要

本地已有 `GET /api/dsh-margin/candidate?id=N`；Margin 客户端尝试 `GET /api/candidates/{id}`。上线前核验当前实例的正文位置/类型、空值、错误标记、最大响应、404/401/超时和编码。字段不支持时标 TBD 并降级，不臆造内容接口。验证新增详情字段不会泄漏到列表或工具输出。

## 验收与测试

1. Markdown、纯文本、空白、缺字段、提取失败但有可读旧正文均显示正确；失败提示不抹去可读内容。
2. 恶意 HTML、`javascript:` 链接、SVG/图片载荷不能执行；代码、表格、中文、长文可阅读。
3. 带筛选/页码打开并返回，列表状态保持；A/B 乱序、失败后重试、卸载与换实例不串文；重试参数使用当前文章。
4. 列表与 agent 工具快照无全文；网络行为仅 GET 详情；无 Margin/Trilium 写入、无自动已读。
5. 在现有 DSH GUI 验证入口、滚动、错误提示、键盘操作及 Margin 降级链接。

## 实施记录（2026-10-25）

- 已实现：列表内「阅读」进入同一主面板；正文按需 GET；Markdown/纯文本/空正文降级；摘要与正文分开；提取失败保留已有正文；错误、重试与返回；请求失效保护；返回保持已挂载列表及筛选状态。
- 已实现：详情正文不出现在列表或 agent 工具输出；不返回原始 HTML。渲染使用 DSH 的 `MarkdownText`，空 `MarkdownDelegateProvider` 隔断继承的本地文件打开能力。手写降级链接仅接受 HTTP(S)。
- 远程图片沿用 DSH 组件的直接加载行为（已核验其懒加载与 no-referrer），**不是隐私沙箱或 SSRF 防护**；页面明确提示访问记录风险，不传递 Margin API token，不启用任意 URL 代理。
- 同 ID、不同实例 URL 的返回被拒绝；已打开文章不会轮询探测外部修改的连接配置。完整的配置变化通知/即时失效验收仍待补充，不能据此宣称所有换实例场景已覆盖。
- 自动化包含本地 HTTP 客户端/代理集成测试、详情默认值、列表/工具全文隔离、请求乱序、错误重试、列表状态和 JSX 行为测试。组件测试使用受控 hooks/Markdown mock，**不替代真实 React DOM、Markdown 安全载荷、浏览器布局/焦点验收**。
- 本轮验证：`npm run typecheck`、`npm run build`、`npm test`（74/74）与 `git diff --check` 均通过。
- 运行集成核对（后续轮次）：当前 Web profile 将 dsh-margin 链接到本仓库；现有 GUI 根页与插件配置路由在无浏览器登录会话的探测中均返回 401。没有使用凭据绕过、没有启动替代服务器。进程检查受本机沙箱限制，尚未验证 dev:web watcher，因此不承诺自动热更新。
- 待验收：现有 DSH GUI 加载、长文滚动、真实 Markdown 的代码/表格/公式/图片及恶意载荷、配置切换、键盘焦点。未更改运行中实例配置，未启用写能力，未停任何后端。

## 本轮补强（2026-10-26）

- 列表滚动位置：进入阅读器前记录列表视口 `scrollTop`，返回且列表重新可见后恢复；不再依赖 `display:none` 元素自带的滚动状态。仍未做真实浏览器布局验收。
- 非 JSON 错误保留状态：非 2xx 且响应不是 JSON 时抛带 HTTP 状态的请求错误，因此 HTML/代理 404 仍映射为 `notFound`，不会降级成 `loadFailed`。
- 配置层拒绝带用户名/密码的 `baseUrl`，避免凭据进入 `marginUrl` 和被渲染的链接。

## 发布与回退

先只上线单篇只读路径，保持写闸门关闭；核验构建与实际 GUI 加载后记录结果。异常时撤回插件内详情入口，恢复 Margin 外链；无需数据迁移，不删除或停止后端。
