## 已确认的后端缺陷（插件侧已拦截，未改后端）

1. **PDF 任务可能从队列消失**：worker 删除占位 FeedEntry 后队列 inner join 取不到行，失败路径不恢复；插件把缺席显示为“未知”，不判成功、不自动重投。
2. **RSS 抓取未使用其自带 SSRF 校验**：`rss_fetcher` 导入 `validate_url`/`is_private_or_loopback` 但未调用；插件只在 host 侧做字面量私网拦截，不是完整防护，因此不提供任意 feed 试抓。
3. **上游错误可能回显敏感输入**：全局 422 处理器序列化 `validation_errors`（含输入值），凭据路由 `str(exc)` 可能含 SQL 参数；插件丢弃全部上游 message/detail，只按状态码回固定文案。
4. **没有 SaveRecord 明细 / external_ref 读取接口**：插件因此不展示 Trilium note id，也不伪造历史记录。
5. **没有导入任务重试/取消、没有幂等键**：重复导入只能靠后端 409（且不返回已存在 candidate id）。
